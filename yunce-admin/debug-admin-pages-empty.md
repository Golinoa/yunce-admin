# 管理后台页面空白调试记录

## 现象

- 管理后台已经能启动
- 登录后页面能看到基础框架
- 业务页面只有“查询 / 重置”等静态表单，没有数据渲染

## 预期

- 用户管理、会员管理、激活码管理、邀请积分等页面应展示接口返回的数据列表

## 当前假设

- 假设 1：前端请求已发出，但响应结构与页面读取字段不一致，导致表格拿到 `undefined`
- 假设 2：前端请求根本没有打到真实后端，而是被代理、拦截器或 baseURL 配置影响
- 假设 3：请求成功但被统一响应拦截器吞掉或改写，页面层拿到的不是预期数据
- 假设 4：登录态虽存在，但部分业务请求因鉴权或菜单模式问题返回空数据
- 假设 5：页面的 `fetch` 生命周期执行了，但请求异常被静默处理，最终只剩空状态 UI

## 调试计划

1. 给前端请求层和目标页面加最小插桩
2. 收集运行时请求 / 响应 / 页面赋值证据
3. 用证据排除假设
4. 确认根因后做最小修复

## 证据与结论

- 已证实 `/users` 请求真实命中后端，且页面成功拿到并赋值 `list + pagination`
- 页面空白的首个根因是前端未全局注册 Ant Design Vue，导致 `a-modal` 等组件解析失败，页面渲染链路中断
- “????-131602 / ????-132038” 不是全局字体问题，而是部分联调测试数据在写入数据库时已经被错误编码
- 已修复联调脏数据标题，并将可二值切换的状态列改为开关交互
- 已继续修复 `邀请规则` 与 `审计日志` 中残留的乱码脏数据
- 修复后接口回查结果：
  - `inviteRules.name = 邀请注册奖励-131602`
  - `auditLogs.detail = 联调活动-132038 / 联调轮播-131602 / 联调套餐-131602`
- 用户后续反馈的 `getUserDetailAsync` 运行时错误也已定位并修复：
  - 根因：`teacher: true` 触发 Prisma 查询 `Teacher` 全字段，其中包含数据库未落库的 `campusId`
  - 修复：改为显式 `select`，仅查询已存在且页面需要的字段
  - 复测：`GET /api/admin/v1/users/:id` 返回 `200`，详情数据可正常读取

## 收口结论

- 根因 1：Ant Design Vue 组件未全局注册，导致页面渲染链路中断
- 根因 2：联调测试数据写入数据库时发生错误编码，导致页面显示 `????`
- 根因 3：`Teacher` 模型与真实数据库存在 schema 漂移，用户详情查询命中了未落库字段
- 用户已确认页面恢复正常，本次调试会话收口，进入后续需求开发
