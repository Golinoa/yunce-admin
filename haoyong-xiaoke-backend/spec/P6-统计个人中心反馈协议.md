## 4. 接口详细规格

### 4.1 教师统计

- **路径**: `GET /api/v1/stats/teacher`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **业务规则**: 聚合当前教师的统计数据

- **响应字段**:
  - `overview`: totalStudents, totalClasses, totalPackages, totalLessonsThisMonth, totalHoursThisMonth
  - `studentTrend`: 近 6 个月学生数量趋势
  - `lessonTrend`: 近 6 个月消课趋势
  - `packageStatus`: ACTIVE/EXPIRED/DEPLETED 套餐数
  - `topStudents`: 消课最多的前 5 个学生

---

### 4.2 学生统计

- **路径**: `GET /api/v1/stats/student/:id`
- **权限**: requireAuth + requireRole(['TEACHER', 'PARENT'])
- **业务规则**:
  - TEACHER: 验证学生归属
  - PARENT: 验证绑定关系

- **响应字段**:
  - `overview`: totalLessons, totalHours, totalPackages, remainingHours
  - `lessonTrend`: 近 6 个月消课趋势
  - `packageUsage`: 各套餐使用率
  - `recentLessons`: 最近 10 条消课记录

---

### 4.3 获取个人资料

- **路径**: `GET /api/v1/profile`
- **权限**: requireAuth + requireRole(['TEACHER', 'PARENT'])
- **业务规则**: 根据 role 返回不同结构

---

### 4.4 更新个人资料

- **路径**: `PUT /api/v1/profile`
- **权限**: requireAuth + requireRole(['TEACHER', 'PARENT'])
- **请求参数**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|----------|------|
| nickname | String | 否 | 1-50 字符 | 昵称 |
| avatar | String | 否 | URL | 头像 |
| phone | String | 否 | 手机号格式，唯一 | 手机号 |
| institution | String | 否 | 0-100 字符（仅 TEACHER） | 机构名称 |

- **业务规则**:
  1. phone 唯一校验（排除自身）
  2. institution 仅 TEACHER 有效

---

### 4.5 提交反馈

- **路径**: `POST /api/v1/feedback`
- **权限**: requireAuth + requireRole(['TEACHER', 'PARENT'])
- **请求参数**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|----------|------|
| type | Enum | 是 | BUG/FEATURE/OTHER | 反馈类型 |
| content | String | 是 | 1-2000 字符 | 反馈内容 |
| contact | String | 否 | 0-100 字符 | 联系方式 |

---

### 4.6 用户协议

- **路径**: `GET /api/v1/agreement`
- **权限**: 公开（无需认证）
- **业务规则**: 硬编码返回协议内容
