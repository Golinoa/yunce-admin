## 4. 接口详细规格

### 4.1 创建消课

- **路径**: `POST /api/v1/lesson-records`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **请求参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| studentId | UUID | 是 | — | 合法 UUID | 学生 ID |
| packageId | UUID | 否 | null | 合法 UUID | 课时套餐 ID |
| classId | UUID | 否 | null | 合法 UUID | 班级 ID |
| scheduleId | UUID | 否 | null | 合法 UUID | 排课 ID |
| lessonDate | String | 是 | — | YYYY-MM-DD | 上课日期 |
| duration | Int | 是 | — | 1-480 | 课时时长（分钟） |
| content | String | 否 | null | 0-2000 字符 | 课程内容 |
| homework | String | 否 | null | 0-2000 字符 | 课后作业 |

- **业务规则**:
  1. 验证 studentId 归属当前教师
  2. 若指定 packageId：
     - 验证套餐归属该学生
     - 验证套餐状态为 ACTIVE
     - 验证 `usedHours < totalHours`（课时不足返回 422）
     - 自动 `usedHours += 1`
     - 若 `usedHours === totalHours`，更新 status = DEPLETED
  3. 若指定 classId，验证班级归属当前教师
  4. 若指定 scheduleId，验证排课归属指定班级
  5. 创建 lesson_records 记录

- **课时不足错误响应**:
```json
{
  "code": 422,
  "data": null,
  "message": "课时不足：套餐\"春季数学套餐\"剩余课时为 0"
}
```

- **成功响应**:
```json
{
  "code": 200,
  "data": {
    "id": "uuid",
    "studentId": "uuid",
    "studentName": "小明",
    "packageId": "uuid",
    "packageName": "春季数学套餐",
    "classId": "uuid",
    "className": "三年级数学班",
    "lessonDate": "2026-06-08",
    "duration": 90,
    "content": "分数运算",
    "homework": "完成练习册 P25-28",
    "status": "NORMAL",
    "remainingHours": 35,
    "createdAt": "2026-06-08T14:30:00.000Z"
  },
  "message": "消课记录创建成功"
}
```

### 4.2 消课列表

- **路径**: `GET /api/v1/lesson-records`
- **权限**: requireAuth + requireRole(['TEACHER', 'PARENT'])
- **查询参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| page | Int | 否 | 1 | >= 1 | 页码 |
| pageSize | Int | 否 | 20 | 1-100 | 每页条数 |
| studentId | UUID | 否 | — | 合法 UUID | 按学生筛选 |
| classId | UUID | 否 | — | 合法 UUID | 按班级筛选 |
| startDate | String | 否 | — | YYYY-MM-DD | 起始日期 |
| endDate | String | 否 | — | YYYY-MM-DD | 结束日期 |

### 4.4 更新消课

- **路径**: `PUT /api/v1/lesson-records/:id`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **请求参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| content | String | 否 | — | 0-2000 字符 | 课程内容 |
| homework | String | 否 | — | 0-2000 字符 | 课后作业 |
| status | String | 否 | — | NORMAL/CANCELLED/MAKEUP | 记录状态 |

- **业务规则**:
  1. 验证记录关联的学生归属当前教师
  2. `packageId` 不可修改（创建后固定）
  3. `status` 从 NORMAL → CANCELLED：触发课时回滚（usedHours -= 1），若套餐为 DEPLETED 则恢复为 ACTIVE
  4. `status` 从 CANCELLED → NORMAL：重新扣减课时（usedHours += 1），检查课时是否充足
  5. 以上状态变更需在事务中执行

- **响应**: 返回更新后的记录

---

### 4.5 删除消课

- **路径**: `DELETE /api/v1/lesson-records/:id`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **业务规则**:
  1. 验证记录关联的学生归属当前教师
  2. 若记录关联了套餐且 status 为 NORMAL，回滚课时（usedHours -= 1）
  3. 物理删除记录
  4. 以上操作需在事务中执行

## 5. 业务逻辑流程图

### 5.1 创建消课

```
POST /lesson-records { studentId, packageId?, classId?, lessonDate, duration, ... }
        │
        ▼
  验证 studentId 归属当前教师
        │
        ▼
  若指定 packageId?
   ┌────┴────┐
   │ 是      │ 否
   ▼         │
  验证套餐归属该学生  │
   │         │
  验证套餐 status=ACTIVE
   │         │
  usedHours < totalHours?
   │         │
  否 → 422 课时不足   │
  是                  │
   │                  │
  usedHours += 1      │
   │                  │
  usedHours == totalHours?
   │ 是 → status=DEPLETED
   │         │
   └────┬────┘
        │
  若指定 classId → 验证班级归属教师
        │
  创建 lesson_records 记录
        │
  返回记录 + remainingHours
```

### 5.2 状态变更（课时回滚/扣减）

```
更新 status: NORMAL → CANCELLED
        │
        ▼
  若有关联 packageId:
        │
        ▼
  usedHours -= 1
        │
        ▼
  若 package.status === DEPLETED:
        │
        ▼
  package.status = ACTIVE

---

更新 status: CANCELLED → NORMAL
        │
        ▼
  若有关联 packageId:
        │
        ▼
  验证 usedHours < totalHours
        │ 否 → 422 课时不足
        │ 是
        ▼
  usedHours += 1
        │
  若 usedHours == totalHours:
        │
        ▼
  package.status = DEPLETED
```

## 8. 风险与注意事项

| 风险 | 说明 | 应对 |
|------|------|------|
| 课时扣减并发 | 多个消课同时扣减同一套餐 | 使用 Prisma 事务 + 乐观锁（updatedAt 检查） |
| 状态变更回滚 | CANCELLED→NORMAL 时课时可能已不足 | 在事务中校验，不足则拒绝 |
| monthlyStats 性能 | 按月聚合需要 GROUP BY | 使用 Prisma $queryRaw 或应用层聚合，限制 12 个月 |
