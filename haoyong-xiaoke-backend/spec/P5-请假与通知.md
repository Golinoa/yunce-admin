## 4. 接口详细规格

### 4.1 创建请假申请

- **路径**: `POST /api/v1/leave-requests`
- **权限**: requireAuth + requireRole(['PARENT'])
- **请求参数**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|----------|------|
| studentId | UUID | 是 | 合法 UUID | 学生 ID |
| startDate | String | 是 | YYYY-MM-DD | 请假开始日期 |
| endDate | String | 是 | YYYY-MM-DD，>= startDate | 请假结束日期 |
| reason | String | 是 | 1-500 字符 | 请假原因 |

- **业务规则**:
  1. 验证 studentId 与家长绑定关系（StudentParent）
  2. status 默认 PENDING
  3. 向教师发送通知（type=LEAVE）

---

### 4.2 请假列表

- **路径**: `GET /api/v1/leave-requests`
- **权限**: requireAuth + requireRole(['TEACHER', 'PARENT'])
- **查询参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| page | Int | 否 | 1 | >= 1 | 页码 |
| pageSize | Int | 否 | 20 | 1-100 | 每页条数 |
| status | String | 否 | — | PENDING/APPROVED/REJECTED | 状态筛选 |
| studentId | UUID | 否 | — | 合法 UUID | 按学生筛选（仅教师） |

- **业务规则**:
  - TEACHER：查询自己学生的请假记录
  - PARENT：查询自己提交的请假记录（通过 studentId 关联 StudentParent）

---

### 4.3 审批请假

- **路径**: `PUT /api/v1/leave-requests/:id/approve`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **请求参数**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|----------|------|
| status | Enum | 是 | APPROVED / REJECTED | 审批结果 |

- **业务规则**:
  1. 验证请假申请归属当前教师的学生
  2. 仅 PENDING 状态可审批
  3. 若 APPROVED：
     - 查找该学生在请假时间段内的 lesson_records（status=NORMAL）
     - 将这些记录 status 更新为 CANCELLED
     - 回滚已扣减的课时（事务中执行）
  4. 向家长发送审批结果通知

- **响应示例**:
```json
{
  "code": 200,
  "data": {
    "id": "uuid",
    "status": "APPROVED",
    "affectedLessons": 3
  },
  "message": "审批成功"
}
```

---

### 4.4 通知列表

- **路径**: `GET /api/v1/notifications`
- **权限**: requireAuth + requireRole(['TEACHER', 'PARENT'])
- **查询参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| page | Int | 否 | 1 | >= 1 | 页码 |
| pageSize | Int | 否 | 20 | 1-100 | 每页条数 |
| type | String | 否 | — | SYSTEM/LEAVE/SCHEDULE/CHECKIN/HOMEWORK | 类型筛选 |
| read | String | 否 | — | true/false | 已读/未读 |

- **业务规则**:
  - receiverId = req.user.profileId
  - 返回 unreadCount

---

### 4.5 发送通知

- **路径**: `POST /api/v1/notifications`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **请求参数**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|----------|------|
| receiverIds | UUID[] | 是 | 1-100 个 | 接收者 profileId 列表 |
| type | Enum | 是 | SYSTEM/LEAVE/SCHEDULE/CHECKIN/HOMEWORK | 通知类型 |
| title | String | 是 | 1-200 字符 | 标题 |
| content | String | 是 | 1-2000 字符 | 内容 |

- **业务规则**:
  1. senderId = req.user.profileId
  2. 批量创建通知记录

---

### 4.6 标记已读

- **路径**: `PUT /api/v1/notifications/:id/read`
- **权限**: requireAuth + requireRole(['TEACHER', 'PARENT'])
- **业务规则**:
  1. 验证 notification.receiverId === req.user.profileId
  2. 更新 read = true

---

## 5. 业务逻辑流程图

### 5.1 审批请假（APPROVED）

```
PUT /leave-requests/:id/approve { status: "APPROVED" }
        │
        ▼
  验证请假归属当前教师学生
        │
        ▼
  验证请假状态为 PENDING
        │
        ▼
  事务开始:
        │
        ▼
  更新请假状态 → APPROVED
        │
        ▼
  查找请假时间段内的 NORMAL 消课记录
        │
        ▼
  遍历消课记录:
        │
        ▼
  ┌─ 更新 status → CANCELLED
  │       │
  │  若关联 packageId:
  │       │
  │  回滚课时（usedHours - 1）
  │       │
  │  若 usedHours < totalHours → status = ACTIVE
  │       │
  └───────┘
        │
        ▼
  事务提交
        │
        ▼
  向家长发送审批结果通知
        │
        ▼
  返回 { affectedLessons }
```
