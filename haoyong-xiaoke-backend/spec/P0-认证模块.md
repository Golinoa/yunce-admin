## 4. 接口详细规格

### 4.1 微信登录

- **路径**: `POST /api/v1/auth/login`
- **权限**: 公开
- **请求头**: `Content-Type: application/json`
- **请求参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| code | String | 是 | — | 非空字符串 | 微信 wx.login() 获取的 code |
| role | Enum | 是 | — | TEACHER / PARENT | 期望角色 |

- **请求示例**:
```json
{
  "code": "wx_login_code_abc123",
  "role": "TEACHER"
}
```

- **响应示例（成功 - 老用户）**:
```json
{
  "code": 200,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "refreshToken": "eyJhbGciOiJIUzI1NiIs...",
    "expiresIn": 7200,
    "user": {
      "id": "uuid",
      "profileId": "uuid",
      "nickname": "张老师",
      "role": "TEACHER",
      "avatar": "https://...",
      "phone": "13800138000",
      "teacher": {
        "id": "uuid",
        "inviteCode": "abc123",
        "institution": "某某培训机构"
      }
    }
  },
  "message": "登录成功"
}
```

- **响应示例（新用户）**:
```json
{
  "code": 200,
  "data": {
    "isNewUser": true,
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "refreshToken": "eyJhbGciOiJIUzI1NiIs...",
    "expiresIn": 7200,
    "user": {
      "id": "uuid",
      "profileId": "uuid",
      "nickname": null,
      "role": "TEACHER",
      "avatar": null,
      "phone": null,
      "teacher": {
        "id": "uuid",
        "inviteCode": "abc123",
        "institution": null
      }
    }
  },
  "message": "新用户注册成功"
}
```

- **业务规则**:
  1. 开发环境使用 Mock：`openId = mock_openid_{code}`，`unionId = mock_unionid_{code}`
  2. 根据 openId 查找 Profile，若存在则直接登录，若不存在则创建新用户
  3. 创建新用户时：先创建 Profile，再根据 role 创建 Teacher 或 StudentParent 记录
  4. 若 role=TEACHER，创建 Teacher 并自动生成 inviteCode
  5. 若 role=PARENT，仅创建 Profile（家长需后续通过 inviteCode 绑定学生）
  6. user.id 为业务 ID（teacher.id 或 student_parent.id 或 profile.id）

- **异常场景**:

| 场景 | HTTP 码 | 业务码 | 错误消息 |
|------|---------|--------|----------|
| code 为空 | 400 | 400 | 参数校验失败：code 不能为空 |
| role 不合法 | 400 | 400 | 参数校验失败：角色必须是 TEACHER 或 PARENT |
| 微信 API 调用失败（生产） | 500 | 500 | 微信登录服务异常 |

### 4.2 手机号注册

- **路径**: `POST /api/v1/auth/register`
- **权限**: 公开
- **请求头**: `Content-Type: application/json`
- **请求参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| phone | String | 是 | — | 正则 `^1[3-9]\d{9}$` | 手机号 |
| role | Enum | 是 | — | TEACHER / PARENT | 角色 |
| nickname | String | 否 | null | 1-50 字符 | 昵称 |
| avatar | String | 否 | null | 合法 URL | 头像 |
| institution | String | 否 | null | 最大 100 字符 | 机构名称（仅 TEACHER） |

- **请求示例**:
```json
{
  "phone": "13800138000",
  "role": "TEACHER",
  "nickname": "张老师",
  "avatar": "https://picsum.photos/seed/t1/200/200",
  "institution": "阳光艺术培训中心"
}
```

- **响应示例（成功）**: 同 login 成功响应

- **业务规则**:
  1. 手机号唯一，若已存在则返回 409
  2. 创建 Profile → 根据 role 创建 Teacher/StudentParent
  3. TEACHER 角色自动生成 inviteCode
  4. institution 字段仅 TEACHER 角色有效，PARENT 角色忽略

- **异常场景**:

| 场景 | HTTP 码 | 业务码 | 错误消息 |
|------|---------|--------|----------|
| 手机号格式错误 | 400 | 400 | 参数校验失败：手机号格式不正确 |
| 手机号已注册 | 409 | 409 | 手机号已注册 |
| nickname 超长 | 400 | 400 | 参数校验失败：nickname 长度不能超过 50 |

### 4.3 获取当前用户信息

- **路径**: `GET /api/v1/auth/me`
- **权限**: 认证用户（requireAuth）
- **请求头**: `Authorization: Bearer <token>`
- **请求参数**: 无

- **响应示例（TEACHER）**:
```json
{
  "code": 200,
  "data": {
    "id": "uuid",
    "profileId": "uuid",
    "nickname": "张老师",
    "role": "TEACHER",
    "avatar": "https://...",
    "phone": "13800138000",
    "teacher": {
      "id": "uuid",
      "inviteCode": "abc123",
      "institution": "某某培训机构",
      "studentCount": 5,
      "classCount": 2
    }
  },
  "message": "success"
}
```

- **响应示例（PARENT）**:
```json
{
  "code": 200,
  "data": {
    "id": "uuid",
    "profileId": "uuid",
    "nickname": "小明爸爸",
    "role": "PARENT",
    "avatar": "https://...",
    "phone": "13800138101",
    "parent": {
      "id": "uuid",
      "relation": "父亲",
      "bindStatus": "BOUND",
      "student": {
        "id": "uuid",
        "name": "小明"
      }
    }
  },
  "message": "success"
}
```

- **业务规则**:
  1. 从 JWT 中提取 profileId，查询 Profile 及关联的 Teacher/StudentParent
  2. TEACHER 返回 studentCount（该教师下学生总数）和 classCount（班级总数）
  3. PARENT 返回绑定的学生信息（仅 BOUND 状态）

- **异常场景**:

| 场景 | HTTP 码 | 业务码 | 错误消息 |
|------|---------|--------|----------|
| Token 缺失 | 401 | 401 | 未提供认证令牌 |
| Token 过期 | 401 | 401 | 认证令牌已过期 |
| 用户不存在 | 401 | 401 | 用户不存在或已被删除 |

### 4.4 刷新 Token

- **路径**: `POST /api/v1/auth/refresh`
- **权限**: 公开
- **请求头**: `Content-Type: application/json`
- **请求参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| refreshToken | String | 是 | — | 非空字符串 | 刷新令牌 |

- **请求示例**:
```json
{
  "refreshToken": "eyJhbGciOiJIUzI1NiIs..."
}
```

- **响应示例（成功）**:
```json
{
  "code": 200,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "refreshToken": "eyJhbGciOiJIUzI1NiIs...",
    "expiresIn": 7200
  },
  "message": "Token 刷新成功"
}
```

- **业务规则**:
  1. 验证 refreshToken 有效性
  2. 从 refreshToken 中提取 profileId
  3. 查询 Profile 确认用户仍存在
  4. 查询 Teacher/StudentParent 获取 userId 和 role
  5. 生成新的 token 和 refreshToken 对
  6. 旧 refreshToken 不做黑名单处理（JWT 自身过期机制保证安全）

- **异常场景**:

| 场景 | HTTP 码 | 业务码 | 错误消息 |
|------|---------|--------|----------|
| refreshToken 为空 | 400 | 400 | 参数校验失败：刷新令牌不能为空 |
| refreshToken 无效 | 401 | 401 | 刷新令牌无效 |
| refreshToken 过期 | 401 | 401 | 刷新令牌已过期，请重新登录 |
| 用户不存在 | 401 | 401 | 用户不存在或已被删除 |

---

### 4.5 退出登录

- **路径**: `POST /api/v1/auth/logout`
- **权限**: 认证用户（requireAuth）
- **请求头**: `Authorization: Bearer <token>`
- **请求参数**: 无

- **响应示例（成功）**:
```json
{
  "code": 200,
  "data": null,
  "message": "退出成功"
}
```

- **业务规则**:
  1. 将当前 Access Token 加入黑名单（内存 Map，key=token, value=过期时间戳）
  2. 黑名单定期清理过期 Token（每次 logout 时顺便清理）
  3. requireAuth 中间件检查 Token 是否在黑名单中

- **异常场景**:

| 场景 | HTTP 码 | 业务码 | 错误消息 |
|------|---------|--------|----------|
| Token 缺失 | 401 | 401 | 未提供认证令牌 |

## 5. 业务逻辑流程图

### 5.1 微信登录流程

```
POST /auth/login { code, role }
        │
        ▼
  Mock: openId = mock_openid_{code}
  Mock: unionId = mock_unionid_{code}
        │
        ▼
  查找 Profile WHERE openId = ?
        │
   ┌────┴────┐
   │         │
  找到      未找到
   │         │
   ▼         ▼
 检查 role  创建 Profile (openId, unionId, role)
   │         │
   ▼         ▼
 查找业务ID  role=TEACHER → 创建 Teacher (inviteCode)
   │         role=PARENT  → 仅 Profile
   │         │
   └────┬────┘
        │
        ▼
  生成 JWT (profileId, userId, role)
        │
        ▼
  返回 { token, refreshToken, expiresIn, user }
```

### 5.2 手机号注册流程

```
POST /auth/register { phone, role, nickname, avatar, institution }
        │
        ▼
  校验手机号格式
        │
        ▼
  查找 Profile WHERE phone = ?
        │
   ┌────┴────┐
   │         │
  已存在    不存在
   │         │
   ▼         ▼
  返回 409   创建 Profile (phone, nickname, avatar, role)
             │
             ▼
           role=TEACHER → 创建 Teacher (inviteCode, institution)
           role=PARENT  → 仅 Profile
             │
             ▼
           生成 JWT
             │
             ▼
           返回 { token, refreshToken, expiresIn, user }
```

## 8. 风险与注意事项

| 风险 | 说明 | 应对 |
|------|------|------|
| Token 黑名单内存泄漏 | 内存中黑名单无限增长 | 每次 logout 时清理过期 Token |
| Mock 微信登录安全性 | 开发环境 Mock 可被滥用 | 生产环境必须切换为真实微信 API |
| refreshToken 安全 | refreshToken 泄露可长期访问 | 有效期 7 天，后续可考虑绑定设备指纹 |
| 并发注册 | 同一手机号并发注册可能绕过唯一检查 | 依赖数据库 phone UNIQUE 约束兜底 |
