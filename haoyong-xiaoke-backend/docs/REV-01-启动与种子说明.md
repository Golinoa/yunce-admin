# REV-01 启动与种子说明

## 默认部署链路

- 默认部署链路只执行数据库迁移和应用启动。
- `docker-compose.yml` 与镜像运行命令均不得自动执行 `prisma db seed`。

## 安全初始化 Seed

- 命令：`npm run db:seed`
- 作用：仅在库内无业务数据时插入演示数据。
- 安全约束：检测到已有业务数据后直接跳过，不执行清库。

## 开发重置 Seed

- 命令：`npm run db:seed:dev-reset`
- 作用：先清空业务数据，再重建本地开发演示数据。
- 使用约束：仅限本地开发环境显式执行，禁止在生产环境执行。

## 推荐使用方式

1. 空库初始化：
   - `npm run db:deploy`
   - 如需演示数据，再显式执行 `npm run db:seed`
2. 本地开发重置：
   - `npm run db:seed:dev-reset`

## 验收关注点

- 重启服务不会清空已有数据。
- 空库可通过迁移后正常启动。
- 开发重置能力保留，但不会被默认启动链路触发。
