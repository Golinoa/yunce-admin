上线验收清单

这份清单是你开发完成后的最终验收标准。只要这里的 P0 场景没有全部通过，就不能算 MVP 闭环完成。 它不是“测试建议”，而是上线开关。

上线判断标准

这次版本只有一个验收目标：一个陌生机构用户从注册开始，能独立走到第一次实际使用。只要需要人工改数据库或临时解释流程，就不算通过。

P0 必须通过

主链路验收

注册、登录、创建机构、创建校区、教师加入、首个教务动作。

P1 建议通过

产品语义验收

免费版 / 会员版文案统一、角色进入正确、异常提示可理解。

P2 可后补

增长与运营验收

积分、广告、活动承接、复杂运营后台等，不阻塞首版上线。

P0 上线验收表

验收项 测试角色 操作步骤 预期结果 失败即代表什么
注册与登录 校长 打开小程序，完成注册或登录 成功进入系统，且不会马上掉线 认证体系未收口，不能进入上线阶段
首次进入创建机构 校长 首次登录后直接进入机构创建页 无需自行找入口，能完成机构创建 状态机与路由守卫未完成
创建首个校区 校长 机构创建完成后继续创建首个校区 成功保存校区并进入教师邀请入口 机构主链路断在第二步
生成临时邀请码 校长 为教师生成 30 分钟或 1 小时邀请码 清楚显示有效期，邀请码可复制和使用 教师加入链路还没有真正建立
教师绑定加入 教师 教师登录后输入邀请码完成加入 成功绑定到对应校区，并进入教师工作台 跨角色主链路未打穿
首个教务动作 教师 完成一个真实动作，例如新增学生 数据保存成功，刷新后仍存在 产品还停留在展示层，没有真实业务闭环
退出再进入 校长 / 教师 关闭小程序或重新进入 保持正确登录态和角色状态，不重复走错流程 会话管理和状态判断未达上线标准

P1 验收表

建议完成

文案与状态

  • 不再出现“未激活不可用”的旧文案
  • 统一改为“免费版可用，会员版解锁高级功能”
  • 校长和教师不会进入错误页面
建议完成

异常提示

  • 邀请码过期有清晰提示
  • 网络错误和保存失败可重试
  • 创建机构或校区失败时不会丢已填写内容

上线前自测顺序

冒烟顺序

先测校长

  • 注册 / 登录
  • 创建机构
  • 创建校区
  • 生成邀请码
再测教师

再测教师

  • 登录
  • 输入邀请码
  • 进入工作台
  • 完成首个教务动作

明确不阻塞上线的内容

1. 积分体系。
2. 签到积分和邀请积分完整规则。
3. 激励广告正式接入。
4. 复杂活动承接页。
5. 家长端深化。
6. 工资、发薪、运营精细化后台。
7. 只要你发现自己在做这些内容，就说明当前偏离了上线主线。
