## 4. 接口详细规格

### 4.1 学生列表

- **路径**: `GET /api/v1/students`
- **权限**: requireAuth + requireRole(['TEACHER', 'PARENT'])
- **查询参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| page | Int | 否 | 1 | >= 1 | 页码 |
| pageSize | Int | 否 | 20 | 1-100 | 每页条数 |
| status | String | 否 | — | ACTIVE/INACTIVE/GRADUATED | 状态筛选 |
| keyword | String | 否 | — | 最大 100 字符 | 按姓名搜索 |
| sortBy | String | 否 | createdAt | createdAt/name/status | 排序字段 |
| sortOrder | String | 否 | desc | asc/desc | 排序方向 |

- **业务规则**:
  1. TEACHER 角色：查询 teacherId = req.user.id 的学生
  2. PARENT 角色：查询绑定的学生（StudentParent 中 bindStatus=BOUND 的学生）
  3. keyword 模糊搜索 name 字段
  4. 列表项包含聚合字段：parentCount, classCount, totalHours, usedHours

- **响应示例**:
```json
{
  "code": 200,
  "data": {
    "list": [
      {
        "id": "uuid",
        "name": "小明",
        "avatar": "https://...",
        "gender": "MALE",
        "birthday": "2015-06-01",
        "phone": "13800138001",
        "remark": "数学薄弱",
        "status": "ACTIVE",
        "parentCount": 2,
        "classCount": 1,
        "totalHours": 48,
        "usedHours": 12,
        "createdAt": "2026-01-15T10:00:00.000Z"
      }
    ],
    "pagination": {
      "page": 1,
      "pageSize": 20,
      "total": 25,
      "totalPages": 2
    }
  },
  "message": "success"
}
```

---

### 4.2 学生详情

- **路径**: `GET /api/v1/students/:id`
- **权限**: requireAuth（TEACHER 验证归属，PARENT 验证绑定）
- **业务规则**:
  1. TEACHER：student.teacherId === req.user.id
  2. PARENT：存在 bindStatus=BOUND 的 StudentParent 记录
  3. 返回关联数据：teacher, parents, classes, coursePackages, recentLessons(最近5条)

- **响应示例**: 见 DOC-5 P1-2

---

### 4.3 创建学生

- **路径**: `POST /api/v1/students`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **请求参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| name | String | 是 | — | 1-50 字符 | 姓名 |
| avatar | String | 否 | null | 合法 URL | 头像 |
| gender | Enum | 否 | null | MALE/FEMALE | 性别 |
| birthday | String | 否 | null | YYYY-MM-DD | 生日 |
| phone | String | 否 | null | 手机号格式 | 电话 |
| remark | String | 否 | null | 0-500 字符 | 备注 |

- **业务规则**:
  1. teacherId = req.user.id（从 Teacher 表获取）
  2. status 默认 ACTIVE

---

### 4.4 更新学生

- **路径**: `PUT /api/v1/students/:id`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **请求参数**: 同创建（全量更新，未传字段保持原值）
- **业务规则**:
  1. 验证 student.teacherId === req.user.id
  2. status 不可通过此接口修改（需用专门接口）

---

### 4.5 删除学生

- **路径**: `DELETE /api/v1/students/:id`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **业务规则**: 软删除，将 status 改为 INACTIVE，不物理删除

---

### 4.6 绑定家长

- **路径**: `POST /api/v1/students/:id/bind-parent`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **请求参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| relation | String | 是 | — | 父亲/母亲/其他 | 关系 |
| phone | String | 是 | — | 手机号格式 | 家长手机号 |

- **业务规则**:
  1. 验证 student.teacherId === req.user.id
  2. 根据 phone 查找 Profile，若存在且 role=PARENT，创建 StudentParent（bindStatus=PENDING）
  3. 若 Profile 不存在，仅创建绑定记录（profileId 暂空，等家长注册后关联）
  4. 若该家长已绑定该学生，返回 409

- **响应示例**:
```json
{
  "code": 200,
  "data": {
    "bindId": "uuid",
    "status": "PENDING",
    "inviteMessage": "请家长使用手机号 13800138002 注册并输入邀请码"
  },
  "message": "绑定邀请已发送"
}
```

- **异常场景**:

| 场景 | HTTP 码 | 业务码 | 错误消息 |
|------|---------|--------|----------|
| 学生不存在 | 404 | 404 | 学生不存在 |
| 非本人学生 | 403 | 403 | 无权操作该学生 |
| 家长已绑定 | 409 | 409 | 该家长已绑定该学生 |

---

### 4.7 家长列表

- **路径**: `GET /api/v1/students/:id/parents`
- **权限**: requireAuth（TEACHER 验证归属，PARENT 验证绑定）
- **响应**: 家长数组，包含 profile 信息和 bindStatus

## 5. 业务逻辑流程图

### 5.1 学生列表查询

```
GET /students?page=1&pageSize=20&status=ACTIVE&keyword=小明
        │
        ▼
  判断 req.user.role
        │
   ┌────┴────┐
   │         │
 TEACHER    PARENT
   │         │
   ▼         ▼
 WHERE      查询 StudentParent
 teacherId  WHERE profileId = req.user.profileId
 = user.id  AND bindStatus = BOUND
   │         │
   ▼         ▼
 AND status  获取 studentId 列表
 = ACTIVE    WHERE id IN (studentIds)
   │         │
   ▼         ▼
 AND name    合并查询条件
 LIKE %keyword%
        │
        ▼
  分页 + 排序
        │
        ▼
  聚合 parentCount, classCount, totalHours, usedHours
        │
        ▼
  返回分页结果
```

### 5.2 绑定家长

```
POST /students/:id/bind-parent { relation, phone }
        │
        ▼
  验证 student.teacherId === req.user.id
        │
        ▼
  查找 Profile WHERE phone = ?
        │
   ┌────┴────┐
   │         │
  找到      未找到
   │         │
   ▼         ▼
 role=PARENT?  创建绑定记录
   │         (profileId 暂空)
 是 / 否       │
   │    忽略    │
   ▼           │
 检查是否已绑定  │
   │           │
 已绑定 → 409   │
 未绑定 → 创建  │
 StudentParent  │
 (PENDING)     │
   │           │
   └─────┬─────┘
         │
         ▼
  返回绑定信息
```

## 8. 风险与注意事项

| 风险 | 说明 | 应对 |
|------|------|------|
| 列表聚合性能 | parentCount/classCount/totalHours/usedHours 需关联查询 | 使用 Prisma include + count，必要时加缓存 |
| 绑定家长时 Profile 不存在 | 手机号未注册的家长 | 先创建绑定记录，等家长注册后关联 |
| PARENT 角色数据隔离 | 家长只能看绑定学生 | Service 层强制过滤 studentId |
