## 4. 接口详细规格

### 4.1 排课列表

- **路径**: `GET /api/v1/schedules`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **查询参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| page | Int | 否 | 1 | >= 1 | 页码 |
| pageSize | Int | 否 | 20 | 1-100 | 每页条数 |
| classId | UUID | 否 | — | 合法 UUID | 按班级筛选 |
| dayOfWeek | Int | 否 | — | 0-6 | 按星期筛选 |

- **业务规则**: 仅查询当前教师的排课（通过 Schedule.teacherId 过滤）

---

### 4.2 创建排课

- **路径**: `POST /api/v1/schedules`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **请求参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| classId | UUID | 是 | — | 合法 UUID | 班级 ID |
| dayOfWeek | Int | 是 | — | 0-6 | 星期几 |
| startTime | String | 是 | — | HH:mm | 开始时间 |
| endTime | String | 是 | — | HH:mm，> startTime | 结束时间 |
| startDate | String | 否 | null | YYYY-MM-DD | 生效开始日期 |
| endDate | String | 否 | null | YYYY-MM-DD，>= startDate | 生效结束日期 |

- **业务规则**:
  1. 验证 classId 归属当前教师
  2. teacherId = req.user.id

---

### 4.3 更新排课

- **路径**: `PUT /api/v1/schedules/:id`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **请求参数**: 同创建
- **业务规则**: 验证 schedule.teacherId === req.user.id

---

### 4.4 删除排课

- **路径**: `DELETE /api/v1/schedules/:id`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **业务规则**: 物理删除

---

### 4.5 套餐列表

- **路径**: `GET /api/v1/course-packages`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **查询参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| page | Int | 否 | 1 | >= 1 | 页码 |
| pageSize | Int | 否 | 20 | 1-100 | 每页条数 |
| studentId | UUID | 否 | — | 合法 UUID | 按学生筛选 |
| status | String | 否 | — | ACTIVE/EXPIRED/DEPLETED | 状态筛选 |

- **业务规则**: 仅查询当前教师的套餐（通过 CoursePackage.teacherId 过滤）
- **列表项包含**: studentName, remainingHours

---

### 4.6 创建套餐

- **路径**: `POST /api/v1/course-packages`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **请求参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| studentId | UUID | 是 | — | 合法 UUID | 学生 ID |
| name | String | 是 | — | 1-100 字符 | 套餐名称 |
| totalHours | Int | 是 | — | >= 1 | 总课时 |
| validStart | String | 否 | null | YYYY-MM-DD | 生效开始 |
| validEnd | String | 否 | null | YYYY-MM-DD，>= validStart | 生效结束 |

- **业务规则**:
  1. 验证 studentId 归属当前教师
  2. teacherId = req.user.id
  3. usedHours 默认 0
  4. status 默认 ACTIVE

---

### 4.7 更新套餐

- **路径**: `PUT /api/v1/course-packages/:id`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **请求参数**: name, totalHours, validEnd（部分更新）
- **业务规则**:
  1. 验证 package.teacherId === req.user.id
  2. usedHours 不可直接修改

---

### 4.8 删除套餐

- **路径**: `DELETE /api/v1/course-packages/:id`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **业务规则**:
  1. 验证 package.teacherId === req.user.id
  2. 若 usedHours > 0，不允许删除，返回 422
  3. 若 usedHours === 0，物理删除
