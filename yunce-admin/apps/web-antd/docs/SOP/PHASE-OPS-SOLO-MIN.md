# 一人运营最小包 — 稳定实施计划

> 目标：OPC 自己盯增长与日常运营，不做企业中台。  
> 方法：纯逻辑先单测 → 页面接线 → `pnpm -F @vben/web-antd test` 绿再继续。

## 范围（只做这 5 项）

| # | 项 | 验收 |
|---|----|------|
| 1 | 看板预警可点进跟进 | 会员到期 → 会员页带 `status`/`profileId`；反馈 → 反馈页带 `handleStatus`/`keyword`；快捷入口带 query |
| 2 | 用户选择器 | 会员开通 / 调积分可用姓名或手机搜索选人，不再手贴 UUID |
| 3 | 机构行操作收纳 | 日常：详情/版本/冻结；危险：有效期/测试/解绑/解散进「更多」 |
| 4 | 增长摘要 | 激活码页按渠道汇总 发/用；邀请页展示规则启用数 + 关系总数 |
| 5 | 飞书试用套餐下拉 | 默认试用 Plan 从会员套餐列表选择 |

## 非目标

MFA、工单 SLA、计费、消息中台、图片上传、审计枚举大改。

## 顺序与稳定闸

```
计划文档 → 单测(红) → 实现纯函数(绿) → 接线页面 → 全量 vitest → 手测清单
```

每项独立可合并；前一项红测未绿不进下一项接线。

## 手测清单（一人 10 分钟）

1. 看板点一条到期用户 → 会员页有筛选/定位感  
2. 看板点一条反馈 → 反馈页状态匹配  
3. 会员「开通」搜手机号选人再开通  
4. 邀请「调积分」搜姓名选人  
5. 机构列表危险操作在「更多」内  
6. 激活码页顶栏有渠道汇总  
7. 飞书「默认试用」可选套餐名
