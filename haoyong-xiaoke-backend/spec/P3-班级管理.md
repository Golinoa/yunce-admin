## 4. 接口详细规格

### 4.1 班级列表

- **路径**: `GET /api/v1/classes`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **查询参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| page | Int | 否 | 1 | >= 1 | 页码 |
| pageSize | Int | 否 | 20 | 1-100 | 每页条数 |
| status | String | 否 | — | ACTIVE/DISBANDED | 状态筛选 |
| keyword | String | 否 | — | 最大 100 字符 | 按名称搜索 |

- **业务规则**:
  1. 仅查询当前教师的班级
  2. keyword 模糊搜索 name 字段
  3. 列表项包含聚合字段：studentCount, scheduleCount

- **响应示例**:
```json
{
  "code": 200,
  "data": {
    "list": [
      {
        "id": "uuid",
        "name": "三年级数学班",
        "subject": "数学",
        "grade": "三年级",
        "schedule": "每周六 14:00",
        "location": "教室 A",
        "status": "ACTIVE",
        "studentCount": 15,
        "scheduleCount": 2,
        "createdAt": "2026-01-15T10:00:00.000Z"
      }
    ],
    "pagination": { "page": 1, "pageSize": 20, "total": 5, "totalPages": 1 }
  },
  "message": "success"
}
```

---

### 4.2 班级详情

- **路径**: `GET /api/v1/classes/:id`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **业务规则**:
  1. 验证 class.teacherId === req.user.id
  2. 返回关联数据：teacher, students, schedules, recentLessons(最近5条)

---

### 4.3 创建班级

- **路径**: `POST /api/v1/classes`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **请求参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| name | String | 是 | — | 1-100 字符 | 班级名称 |
| subject | String | 否 | null | 0-50 字符 | 科目 |
| grade | String | 否 | null | 0-50 字符 | 年级 |
| schedule | String | 否 | null | 0-200 字符 | 上课时间描述 |
| location | String | 否 | null | 0-200 字符 | 上课地点 |

- **业务规则**:
  1. teacherId = req.user.id
  2. status 默认 ACTIVE

---

### 4.4 更新班级

- **路径**: `PUT /api/v1/classes/:id`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **请求参数**: 同创建（全量更新）
- **业务规则**: 验证 class.teacherId === req.user.id

---

### 4.5 删除班级

- **路径**: `DELETE /api/v1/classes/:id`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **业务规则**: 软删除，status 改为 DISBANDED

---

### 4.6 班级学生列表

- **路径**: `GET /api/v1/classes/:id/students`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **业务规则**:
  1. 验证 class.teacherId === req.user.id
  2. 返回 ClassStudent 关联的学生信息

- **响应示例**:
```json
{
  "code": 200,
  "data": [
    {
      "id": "uuid",
      "name": "小明",
      "avatar": "https://...",
      "gender": "MALE",
      "phone": "13800138001",
      "joinedAt": "2026-01-15T10:00:00.000Z"
    }
  ],
  "message": "success"
}
```

---

### 4.7 添加学生到班级

- **路径**: `POST /api/v1/classes/:id/students`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **请求参数**:

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|------|----------|------|
| studentId | UUID | 是 | 合法 UUID | 学生 ID |

- **业务规则**:
  1. 验证 class.teacherId === req.user.id
  2. 验证学生归属当前教师
  3. 验证学生未已在该班级中（已存在返回 409）
  4. 创建 class_students 记录

- **异常场景**:

| 场景 | HTTP 码 | 错误消息 |
|------|---------|----------|
| 班级不存在 | 404 | 班级不存在 |
| 非本人班级 | 403 | 无权操作该班级 |
| 学生不存在 | 404 | 学生不存在 |
| 非本人学生 | 403 | 无权操作该学生 |
| 学生已在班级 | 409 | 该学生已在班级中 |

---

### 4.8 移除班级学生

- **路径**: `DELETE /api/v1/classes/:id/students/:studentId`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **业务规则**:
  1. 验证 class.teacherId === req.user.id
  2. 删除 class_students 记录

---

### 4.9 班级签到

- **路径**: `POST /api/v1/classes/:id/checkin`
- **权限**: requireAuth + requireRole(['TEACHER'])
- **请求参数**:

| 字段 | 类型 | 必填 | 默认值 | 校验规则 | 说明 |
|------|------|------|--------|----------|------|
| date | String | 是 | — | YYYY-MM-DD | 签到日期 |
| studentIds | UUID[] | 是 | — | 1-100 个 | 学生 ID 列表 |
| packageId | UUID | 否 | null | 合法 UUID | 统一扣减的套餐 |
| content | String | 否 | null | 0-2000 字符 | 课程内容 |
| homework | String | 否 | null | 0-2000 字符 | 课后作业 |

- **业务规则**:
  1. 验证 class.teacherId === req.user.id
  2. 验证所有 studentIds 归属当前教师且在该班级中
  3. 若指定 packageId，验证套餐归属每个学生且状态 ACTIVE
  4. 批量创建 lesson_records，每个学生一条记录
  5. 批量扣减课时（事务中执行）
  6. 部分学生课时不足时，该学生跳过，其他学生正常创建

- **响应示例**:
```json
{
  "code": 200,
  "data": {
    "createdCount": 15,
    "failedCount": 0,
    "records": [
      {
        "studentId": "uuid",
        "studentName": "小明",
        "recordId": "uuid",
        "status": "success"
      }
    ]
  },
  "message": "签到成功，共创建 15 条消课记录"
}
```

## 5. 业务逻辑流程图

### 5.1 班级签到

```
POST /classes/:id/checkin { date, studentIds, packageId?, content?, homework? }
        │
        ▼
  验证 class.teacherId === req.user.id
        │
        ▼
  遍历 studentIds:
        │
        ▼
  ┌─ 验证学生归属教师 ── 否 → 跳过(failed)
  │       │
  │      是
  │       │
  │  验证学生在班级中 ── 否 → 跳过(failed)
  │       │
  │      是
  │       │
  │  若指定 packageId:
  │       │
  │  验证套餐归属学生 ── 否 → 跳过(failed)
  │       │
  │  验证套餐 ACTIVE ── 否 → 跳过(failed)
  │       │
  │  验证课时充足 ── 否 → 跳过(failed)
  │       │
  │      是
  │       │
  │  创建消课记录 + 扣减课时
  │       │
  │  status = success
  │       │
  └───────┘
        │
        ▼
  返回 { createdCount, failedCount, records }
```

## 8. 风险与注意事项

| 风险 | 说明 | 应对 |
|------|------|------|
| 签到批量操作 | 100 个学生同时扣减课时 | 使用事务，部分失败不影响其他学生 |
| 班级删除影响 | 班级下有学生和消课记录 | 软删除，不级联删除关联数据 |
| 签到幂等性 | 同一日期重复签到 | 当前不限制，后续可加唯一约束 |
