我检测后的问题摘要

这部分只放“影响 MVP 上线”的问题，不放代码风格类噪音。完整版本见 `问题记录` 子页。

P0

前端登录续期未收口

401 后自动刷新令牌的闭环还不稳定，这是当前最容易影响真实用户使用的阻塞项。

P0

机构主体与教师加入链路未打穿

业务规则已经明确，但产品和技术尚未完全按“机构 -> 校区 -> 临时邀请码 -> 教师加入”收口。

P1

Mock 残留较多

学生、课程、认证等模块仍有较多 `USE_MOCK` 分支，影响真实联调效率。

P1

后台有能力，前台承接不足

激活码、会员、邀请、内容运营已经有基础，但当前小程序还没有完整承接页。

免费开源接入建议

你的当前阶段不适合引入“大而全”的新系统，只适合接入能补关键短板的工具。完整版本见 `开源接入选项` 子页。

推荐

Umami

适合做官网、落地页、帮助页的访问分析，部署轻，适合 1 人团队快速搭建。

按需

Formbricks

适合后续做用户反馈、流失回访问卷和简单 NPS，但不建议在首版上线前强接。

补位

Appsmith

不用于替换现有后台，适合临时补一个内部运营工具或数据核对台。
