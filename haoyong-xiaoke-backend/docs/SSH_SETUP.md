# ============================================
# SSH 密钥配置指南
# 用于：Gitee CI/CD 自动部署
# ============================================

# 1. 生成 SSH 密钥对（在本地或服务器上执行）
ssh-keygen -t ed25519 -C "xiaoke-deploy@chancore.cn" -f ~/.ssh/id_ed25519_deploy

# 2. 查看公钥
cat ~/.ssh/id_ed25519_deploy.pub

# 3. 将公钥添加到 Gitee
# 访问：https://gitee.com/profile/ssh_keys
# 点击「添加公钥」，粘贴公钥内容

# 4. 将私钥添加到 Gitee 仓库的「部署密钥」
# 仓库 → 设置 → 部署公钥 → 添加
# 粘贴私钥内容（id_ed25519_deploy，没有 .pub 后缀）

# 5. 或者添加为仓库的「私有变量」
# 仓库 → 设置 → 流水线 → 变量管理
# 添加变量：SSH_PRIVATE_KEY
# 值：粘贴私钥内容

# 6. 验证连接
ssh -T git@gitee.com

# 预期输出：Welcome to Gitee, yourname!
